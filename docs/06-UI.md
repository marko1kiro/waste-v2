# 06 — UI: Design System & Pages

## 1. Theme: Dark Cyberpunk / Neo-Brutalism

### Color Palette
| Token | Hex | Penggunaan |
|-------|-----|------------|
| Background | `#0a0a0a` / `#111` | Main page bg |
| Surface | `#1A1C22` / `#23262F` | Cards, containers |
| Border | `#2a2a2a` / `rgba(79,209,255,0.08)` | Borders |
| Primary accent | `#4FD1FF` | Headings, icons, active state |
| Primary glow | `rgba(79,209,255,0.15)` | Glow effects |
| Warning accent | `#FFE500` | CTA buttons, highlights |
| Text primary | `#E5E7EB` / `#f0f0f0` | Body text |
| Text muted | `#9CA3AF` / `#555` / `#666` | Secondary text |
| Text dim | `#444` | Placeholder |
| Danger | `#ef4444` | Errors, delete |
| Success | `#4ADE80` | Success states |

### Typography
| Style | Font | Size | Weight |
|-------|------|------|--------|
| Heading | System stack | `text-xl` (20px) | `font-black` (900) |
| Subheading | System stack | `text-sm` (14px) | `font-bold` (700) |
| Body | System stack | `text-sm` (14px) | `font-medium` (500) |
| Label | System stack | `text-[10px]` | `font-black` (900) uppercase |
| Muted | System stack | `text-xs` (12px) | `font-sans` (400) |

### Shadow Tokens
```css
--shadow-nb-sm: 2px 2px 0px #000;
--shadow-nb-md: 3px 3px 0px #000;
--shadow-nb-lg: 4px 4px 0px #000;
--shadow-nb-yellow: 3px 3px 0px rgba(255,229,0,0.3);
--shadow-card: 4px 4px 8px rgba(0,0,0,0.4), -2px -2px 6px rgba(255,255,255,0.03);
```

## 7. PWA Requirements

- **manifest.json**: name "AWAS", icons 144/192/512, theme_color `#0a0a0a`
- **Service worker**: `public/sw.js` — network-first strategy
- **Offline**: Form draft bisa di-save ke localStorage, tapi submit butuh koneksi
- **Install prompt**: PWAInstallPrompt component

---

## 8. Responsive Design

### Breakpoints
| Breakpoint | Target |
|-----------|--------|
| Mobile (default) | iPhone SE — iPhone 15 |
| `lg: (1024px)` | Tablet & desktop |
| `xl: (1280px)` | Desktop wide |

### Mobile-first approach
- Sidebar desktop → Bottom nav mobile
- Multi-column → Single column stack
- Font sizes smaller on mobile
- Touch-friendly input sizing (min 44px tap target)
